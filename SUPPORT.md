## 🛠️ When to Open a GitHub Issue

Please open a GitHub Issue **only** for:
- **Confirmed Bugs**: Unexpected exceptions, UI calculation glitches, or broken API routes that can be reproduced with consistent steps.
- **Feature Requests**: Well-reasoned proposals for platform enhancements or API additions.

> [!NOTE]
> For general configuration help, debugging your own custom Docker deployments, or general questions, please use **GitHub Discussions** instead of opening an issue.
